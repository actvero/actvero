# organization 模块

提供当前组织的基本设置，社区与 SaaS 模式均可使用。组织管理员在“组织管理 → 组织设置”修改组织名称、查看组织 ID 和创建时间；普通成员与仅有平台运营身份的账号不能使用此接口。当前不提供公司部门树功能。

组织名称通过当前值校验并串行保存，过期草稿返回冲突，需重新载入后核对。修改保留组织 ID、成员及资源归属，并写入组织操作记录。启停组织和创建其他组织仍属于 SaaS 平台运营功能。

系统边界见 [架构](../../../../docs/ARCHITECTURE.md)，身份与授权见 [身份流程](../../../../docs/IDENTITY-FLOW.md)。接口字段以 [OpenAPI](../../../../docs/api/openapi.json) 为准。
