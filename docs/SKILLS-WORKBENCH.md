# Skills 管理

管理员上传单技能 ZIP 或文件夹包，预览内容、维护展示资料与类别，并发布可供授权成员使用的版本。版本包与平台权限元数据分别维护。

## 文件处理

上传检查路径、大小、压缩包结构及预览格式，防止路径穿越和不受控文件读取。包内说明或命令是内容数据，不应因为预览就被执行。

## 版本与授权

技能只有一个当前生效版本；更新版本不意味着所有客户端立即自动安装。草稿、发布状态、资源授权和用户本地安装状态分别表达。

管理员可选择平台图标、上传图像或跟随包图标。标准包下载不应悄悄嵌入平台私有凭据。
