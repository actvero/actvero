# 模型渠道

管理员在渠道页面配置供应商模块、BaseURL、凭据和允许操作。BaseURL 预填供应商完整默认地址，可直接修改，包含所需版本路径（例如百炼的 `/compatible-mode/v1`）；不再单独选择地址方式或填写接口前缀。已有渠道未修改 BaseURL 时保留原连接配置和请求目标，修改地址时需重新提供密钥。

## 配置与使用

保存渠道不调用上游。目录检查读取上游模型目录；登记模型后还需要显式绑定、操作配置、价格和成员授权，才能通过正式入口使用。

供应商预设提供连接地址、认证方式、目录协议和调用协议。模型清单通过当前渠道凭据请求供应商目录接口，不预置模型 ID，也不以公开资料或 SDK 模型库代替接口结果。获取成功后直接展示列表与数量，可搜索、全选匹配结果，或补充手动模型 ID。选择“登记并配置”可携带渠道与上游模型进入配置；“仅登记”保留在渠道清单中。

OpenAI 兼容供应商按对应产品的接口前缀读取 `/models`，包括火山方舟 `/api/v3/models`、Kimi `/v1/models`。Anthropic 使用 `x-api-key` 与 `after_id` 分页，Gemini 使用 `x-goog-api-key` 与 `pageToken` 分页。百炼默认兼容地址的目录读取同源 `/api/v1/models`，解析 `output.models[].model` 并按 `page_no` 翻页；自定义兼容前缀保留其 `/models` 路径。

目录请求限制总超时、总大小 2 MB、最多 10 页和 1000 个模型，不跟随重定向、不使用供应商返回的 URL 跳转。达到分页上限时明确标记部分结果；认证失败、权限不足、目录不存在、限流和网络错误分别提示。失败不会换成静态列表，也不会清空已选或已登记模型。列表是供应商的目录响应，具体模型是否已开通、能否执行某种操作，仍需通过调用诊断确认。

已有渠道成功获取的模型列表保存在服务端，编辑页和详情页共用；关闭弹窗、切换页面或刷新浏览器后仍显示上次结果与更新时间。只有点击“重新获取”才重新请求上游，失败保留原列表，成功的空列表也会保存。修改名称、说明、启停、接口选项或登记模型不清空列表；保存新的地址、认证方式或 API Key 后旧缓存失效。修改连接但尚未保存的编辑预览、新建与复制渠道的临时预览不会覆盖已有渠道缓存。

管理员渠道详情通过 `model_directory` 返回缓存 ID、获取时间、候选模型和分页完整性（历史缓存未记录时为 null）。缓存不按时间自动删除，登记候选时校验当前缓存 ID 和模型范围；连接变更或新一次获取会使旧 ID 失效。缓存列表不是调用权限或可用性证明，也不会自动登记模型。

模型参数补全继续使用精确匹配的 SDK 或公开模型元数据，并标记来源；这些建议不作为渠道模型库存。未知参数和价格保留未知，不自动设置为免费。

渠道状态、目录结果、诊断结果和模型绑定的可用状态分别表达。人工停用不能被测试成功悄悄恢复；管理员诊断旁路也不能成为成员调用旁路。

## 预设维护范围

新增渠道提供 OpenAI、Anthropic、Gemini、DeepSeek、硅基流动、AIHubMix、火山方舟普通 API、Kimi、阿里云百炼，以及自定义 OpenAI 兼容连接。

智谱 GLM、千问按量 API、千问 Token Plan、火山 Agent Plan 和 Coding Plan 暂停新增：这些产品的目录适配还缺少充分验证。暂停不表示供应商没有模型列表接口。重新开放前，需要核对对应产品的官方地址、凭据类型、目录接口和响应格式，并补充适配测试；套餐产品不能沿用普通 API 的验证结论。

暂停的预设不出现在新增选择器，也不能复制为新渠道。`GET /llm/providers` 仍返回其资料，以 `available_for_new_channels: false` 表达新增限制；创建接口同步拒绝。已有渠道继续保留地址、凭据、模型登记、编辑、目录检查与调用路径，已完成的创建回执仍可重放，不自动迁移到其他产品或删除渠道。

保留预设表示维护连接与目录适配，不保证某个账号拥有所有模型的调用权限。协议测试使用隔离的模拟上游；真实账号的开通范围仍以目录结果和调用诊断为准。

## 测试与失败

单项诊断提供操作参数、UUID 回执与执行记录；支持的 Chat 诊断可流式展示。批量诊断逐项记录结果，失败或未确认项不自动重发。响应丢失时先查询原请求记录。

私有网络白名单、目录信息和供应商能力声明不能代替真实调用验证。
