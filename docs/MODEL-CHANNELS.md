# 模型渠道

管理员在渠道页面配置供应商模块、API 基础 URL、凭据和允许操作。官方地址与自定义地址是用户可见选项；兼容旧地址的内部规则不应在普通保存时改写既有目标。

## 配置与使用

保存渠道不调用上游。目录检查读取上游模型目录；登记模型后还需要显式绑定、操作配置、价格和成员授权，才能通过正式入口使用。

渠道状态、目录结果、诊断结果和模型绑定的可用状态分别表达。人工停用不能被测试成功悄悄恢复；管理员诊断旁路也不能成为成员调用旁路。

## 测试与失败

单项诊断提供操作参数、UUID 回执与执行记录；支持的 Chat 诊断可流式展示。批量诊断逐项记录结果，失败或未确认项不自动重发。响应丢失时先查询原请求记录。

私有网络白名单、目录信息和供应商能力声明不能代替真实调用验证。
