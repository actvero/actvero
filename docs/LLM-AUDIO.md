# 语音合成与转写

接口包含 `/api/llm/v1/audio/speech` 和 `/api/llm/v1/audio/transcriptions`。模型需要显式开放相应操作；支持格式、上传限制和参数以当前模型配置与接口契约为准。

## 媒体与计量

受控音频路径验证格式与内容，客户端按响应类型处理文件或文本。测量得到的文件时长不是上游计费 usage，不能冒充供应商确认的计量。

## 范围

这里不承诺实时语音、任意编解码器或每个供应商都支持相同参数。诊断与正式调用分别鉴权和记录。
