# 桌面登录与设备会话

桌面采用公共 OIDC client、S256 PKCE 和临时回环回调，通过系统浏览器完成真实用户登录。客户端负责 state、nonce、回调来源及取消状态校验。

## 接入流程

读取实例发现信息，发起设备登录并打开浏览器，核验回调后交换凭据并持久保存。多组织模式下按服务端提供的资格选择组织，不能按名字猜测组织标识。

## 续期与退出

Web、桌面和 CLI 的会话策略独立。桌面恢复协议需要先保存新的凭据再确认；响应丢失按原请求标识恢复，不能用旧状态覆盖已经确认的新会话。

退出或撤销设备后停止后续访问。强制换账号打开可填写新身份的表单。管理控制台接口不接受桌面资源令牌作为 Web 会话替代。

## 接口

完整请求和响应字段以 [OpenAPI](api/openapi.json) 中 desktop 标签为准。资源接入分别见 [MCP](DSH-MCP-ACCESS.md)、[Skills](DSH-SKILLS-ACCESS.md) 与 [专家](DSH-EXPERTS-ACCESS.md)。
