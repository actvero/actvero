# MCP 服务管理

管理员添加 HTTP/SSE 等当前支持的 MCP 连接配置，维护服务资料、身份方式和访问范围。服务提供 Tools、Prompts、Resources 和资源模板，能力是否可用取决于实际发现与授权。

## 发现与开放

新服务默认关闭。首次发现、重新发现及能力执行定义变化遵循不同的保留/关闭规则，不能因目录刷新而自动扩大成员权限。编辑不会回显秘密。

## 个人连接

连接组织共享凭据与成员个人授权分别处理。需要个人授权时不能回退借用管理员凭据。管理员测试不代表所有成员已经连接成功。

## 网络

默认公网策略与显式内网白名单独立配置。目录发现、诊断成功、服务启用和成员可调用是不同状态。客户端接入见 [MCP 桌面契约](DSH-MCP-ACCESS.md)。
