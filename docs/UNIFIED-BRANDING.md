# 统一品牌配置

平台运营可配置名称、方形图标、横版标志和适用的浅深色素材。品牌配置服务于 Web、身份页面、邮件与客户端发现；组织名称和个人头像独立管理。

## 上传与发布

接受当前接口允许的静态 PNG/JPEG/WebP，校验大小、像素与内容后重新编码。保留完整比例，不以头像裁剪方式处理横版标志。SVG 与动画不能直接作为上传格式。

先编辑草稿再整组保存；冲突时读取当前版本。图片使用稳定标识和缓存信息，客户端按照品牌修订刷新。

## 身份与邮件

Keycloak 主题通过专用品牌字段消费资料；同步失败可重试，不回滚已经保存的 Web 设置。登录资源 URL 包含内容版本，用于刷新 CSS/JS 缓存。

邮件中的历史图片链接仍可能被已发邮件引用，不能随意删除。生产恢复需同时考虑身份库、业务库与配置。
