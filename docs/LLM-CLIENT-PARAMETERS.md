# 模型客户端参数

客户端先读取已授权模型目录，按返回的操作能力与参数策略构造请求。服务端使用当前组织、成员、资源开关和价格策略再次校验。

## 对话

`/api/llm/v1/chat/completions` 提供普通及 SSE 响应。工具调用与工具结果按模型协议成对传递；跨轮次保留服务端返回且协议要求的续传字段，不以展示文本替代结构化结果。

## 能力限制

默认值、上下文限制、思考模式和媒体格式由模型配置、供应商和实际 SDK 能力共同决定。不向每个模型盲传同一组参数。

## 重试

遇到权限或配置变化时刷新目录。执行结果未知时先查原请求回执；不能把网络断开当作上游未执行并无条件重发。
