# 模型操作

一个模型可配置多个操作，操作是否开放与渠道是否启用分别控制。管理员通常从渠道来源配置模型，再在模型配置中维护调用范围与高级操作设置。

## 接口范围

当前机器契约包含 Chat Completions、Embeddings、Rerank、图片生成、语音合成与转写入口。操作存在不表示每个供应商或模型都支持该操作。

## 计量

计量类型和历史价格决定结算方式。Token、字符、搜索单位、图片张数及音频相关字段按实际操作处理，缺失值不补零。参数限制见 [客户端参数](LLM-CLIENT-PARAMETERS.md)。
