# 模型执行与记录

正式模型调用通过统一身份、授权与额度检查，再交由 SDK 执行。应用记录调用根对象、逐次尝试、可观察到的计量以及结算状态。

## 结果与证据

上游成功不等同于客户端确认收到全部输出；流式中断、取消和未知计量应保留各自状态。管理员诊断与成员消费使用不同来源标记，不能将普通诊断混入成员预算。

## 幂等与结算

请求标识与规范化请求内容共同决定幂等行为。同标识异内容必须报冲突；响应丢失先查询。自动结算与人工核对都遵守唯一性、历史价格和终态保护。

同一次受理时刻用于额度检查、调用记录和结算记录，数据库提交耗时不会改变周期归属。缺失缓存单价或相互矛盾的用量计数保留待核对，不按零费用处理；计量核查不阻断 SDK 已生成的模型输出。周期规则见 [额度策略](QUOTA-POLICIES.md)。

账务 outbox 的重放处理记录，不重新调用模型。运维需成套备份该持久目录和数据库，见 [服务器维护](SERVER-DEPLOYMENT.md)。

并发写入的最终证据不会被较早日志的确认清理删除。调用因中断恢复而暂时标为未知后，迟到的最终证据可更新执行事实；只有该首次中断恢复形成、尚未经人工核对的结算版本允许自动补账。管理员已处理的状态和版本保持有效。
