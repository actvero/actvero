# 客户端下载管理

公开 `/download` 展示已发布的客户端版本与安装包链接。平台运营在站点与品牌设置中维护版本、平台、架构、链接和发布状态。

页面按公开目录中的平台与架构匹配后台推荐，不会把最新列出的版本自动当成推荐。版本号、安装包格式、系统要求、文件大小、更新说明与历史下载均来自接口；没有大小或校验值时不生成示例数值。不同目标的推荐版本不一致时，各自展示版本号。

浏览器仅用于识别当前操作系统，不据此推断 CPU。页面按系统列出已发布的架构，每个架构直接提供对应推荐版本的下载入口；未设置推荐的架构不提供主下载，可在历史目录手动选择版本。下架或刷新后已消失的架构会清除原下载链接；读取失败单独显示重试，不当作尚未发布。系统要求、文件大小和校验信息保留在历史版本详情中。

## 发布流程

先保存草稿和包资料，再明确发布、推荐或下架。公开页面只读取可见版本，后台记录管理操作。并发修改需要版本校验，响应丢失按回执查询。

## 范围

下载目录支持原有外部安装包链接；对象存储上传与客户端更新通道通过[客户端更新发布](CLIENT-DISTRIBUTION.md)维护，发布结果同步到下载目录。平台不负责签名、生成安装器或证明二进制可信。没有实际发布包时显示空状态，不能使用示例链接冒充可下载产品。
