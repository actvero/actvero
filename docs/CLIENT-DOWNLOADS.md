# 客户端下载管理

公开 `/download` 展示已发布的客户端版本与安装包链接。平台运营在站点与品牌设置中维护版本、平台、架构、链接和发布状态。

## 发布流程

先保存草稿和包资料，再明确发布、推荐或下架。公开页面只读取可见版本，后台记录管理操作。并发修改需要版本校验，响应丢失按回执查询。

## 范围

下载目录支持原有外部安装包链接；对象存储上传与客户端更新通道通过[客户端更新发布](CLIENT-DISTRIBUTION.md)维护，发布结果同步到下载目录。平台不负责签名、生成安装器或证明二进制可信。没有实际发布包时显示空状态，不能使用示例链接冒充可下载产品。
