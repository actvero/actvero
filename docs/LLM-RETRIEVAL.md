# 向量与重排

模型可开放 `/api/llm/v1/embeddings` 与 `/api/llm/v1/rerank`。请求受模型操作配置、资源授权及成员额度检查。

## 配置

向量用途需明确模型、维度与向量空间；已有客户端依赖的空间约定不能随意改变。重排按独立操作与计量规则处理。

## 边界

向量接口可供外部调用者维护自己的检索数据与索引，也用于平台的[知识库](KNOWLEDGE.md)。知识库当前提供文档解析、切片、受权限控制的检索和稳定原文引用；外部调用者的索引生命周期仍由调用者管理。
