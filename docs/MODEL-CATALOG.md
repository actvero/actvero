# 模型管理

模型目录把上游渠道能力组织为对成员公开的模型。管理员先选择来源，再维护技术标识、展示资料、绑定、参数、价格和使用范围。

## 操作

创建模型不会自动开放调用。启用前确认相应操作、渠道绑定、价格和授权。不同操作可以有不同参数和计量类型，来源相似不代表能力完全相同。

技术标识与显示名称分开；修改技术标识可能影响客户端请求。平台可用的目录字段以实际 OpenAPI 与返回值为准。

## 生命周期

归档模型会关闭正式调用；恢复后需明确重新开启。保存的绑定、价格和操作资料不因归档自动抹除。并发配置冲突应读取最新版本后处理。
