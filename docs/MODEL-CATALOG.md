# 模型管理

模型与渠道独立管理，通过渠道映射关联。模型维护对成员公开的标识、展示资料、参数、价格和使用范围；创建模型无需先配置渠道。

## New API 网关模式

组织配置 New API 网关后，模型入口使用其原版模型管理、供应商管理、资料同步和定价组件，沿用模型名称、名称匹配规则、标签、图标、端点声明与展示策略。新建和编辑使用同一表单；保存模型资料不要求已有渠道，也不会创建渠道或自动配置价格。

精确匹配的模型可在“模型资料”填写展示名称，与资料一起保存。桌面目录使用该名称；留空恢复使用调用 ID。后台列表同时显示展示名称和调用 ID，复制按钮仍复制调用 ID。展示名称按组织保存，修改它保留成员权限、渠道映射、价格和资源身份，不会自动开放模型；公共资料同步也不会覆盖它。已有桌面端读取目录的 `name` 字段，无需重新打包，重新加载模型目录后生效。

模型列表同时列出已保存的资料和渠道中尚未补充资料的模型，主要显示成员开放范围、发布状态和生效定价。已开放且检查发现阻塞问题的模型显示“待维护”，已开放且无已知阻塞显示“已发布”，未开放显示“未发布”。点击状态进入“使用设置”查看接入检查及处理入口。广场展示、渠道与分组、标签和同步策略可从列设置中查看；资料匹配规则只维护元数据，成员访问针对具体模型配置。名称匹配只影响资料归属，价格按具体模型配置。定价编辑保留原版计费表达式、分档、输入输出与缓存价格、货币和费用预览；未设置价格仍显示未设置，显式保存的 0 才表示免费。

“同步资料”先加载公共资料预览，可搜索本站模型或上游模型列表，逐项选择新增模型与覆盖字段，确认后再应用。同步保留来源和记录版本校验；不自动修改渠道、分组访问权限或价格。“同步价格”单独预览并选择来源，价格写入保留版本校验。供应商支持资料维护、关联模型查询、归属分配、合并和删除前的影响预览。

模型资料、定价、渠道与分组、使用设置位于同一个模型窗口。展示资料与模型能力参数共同保存；定价和使用设置各自保存。点击列表中的模型名称打开窗口，再选择相应标签。点击价格可打开定价分区。切换标签保留未保存的参数和访问设置，关闭时提示放弃修改；保存中不能关闭窗口。

“使用设置”维护模型默认值、允许成员调整的选项及 Actvero 成员授权，独立于 New API 的广场展示策略。界面配置开放开关和使用范围（仅管理员、全体成员或指定成员），访问编辑保留已配置的用途、参数及参数来源。未开放设置可以在渠道、价格或参数尚未完善时保存。正式开放前自动校验调用连接、启用渠道、价格、美元积分换算和必要参数；正常时显示就绪状态，缺项时显示原因和相关入口，保存时再次校验。检查不调用供应商或启动额度时钟。已开放模型的渠道后续异常时，保留授权设置并单独标注接入问题。实际登录、访问密钥和请求额度仍在正式调用时校验，配置就绪不保证真实连通性。组织管理员权限与 CSRF 在服务端校验，New API 管理令牌不进入浏览器。云 GPU 部署不包含在此入口。

组织管理员在“模型资料 → 能力与限制”填写上下文、最大输出和已知能力，未知项留空。模型详情右上角的“从远程拉取”可按名称、模型 ID 或供应商查询 Models.dev。选中结果后，可预览当前值和公开资料。“填入空白”将缺少的参数和定价写入草稿。“覆盖已有值”直接保存已有模型的远程参数和可转换报价，完成后回到原来的标签页。定价需要相应管理权限，复杂报价供核对。参数和定价分别保存，部分保存失败时预览会显示结果。

已保存为自动识别的旧模型在保存新的模型资料前，继续根据当前渠道映射解析能力。火山 Agent Plan 的旧自动配置使用与标准模板匹配的供应商资料，保留已验证的思考方式和输入输出限制。保存模型资料后，使用保存的参数；网关仍按渠道处理供应商协议。

New API 调用别名中的内部英文空格原样保留，检查、访问设置与桌面目录使用同一名称，不自动改名。网关调用标识最长 128 字符，需以英文字母或数字开头，不含首尾空格、逗号或控制字符；直接管理模式的技术名称沿用不含空格的规则。不支持的名称明确提示格式问题，不持续显示加载中。“使用设置”中的接入检查列出未关联渠道、缺少能力资料或未配置价格等原因。展示资料缺失不等于运行参数缺失，保存展示资料不会自动开放成员访问。

“使用设置”的摘要显示已知的模型上限、能力声明和推理选项。网关对话默认支持流式输出。已声明的图片输入通过授权目录传给桌面端；当前对话通道支持文本和图片输入、文本输出。

图片对话通过目录中的 `image_input` 提供传输限制：单张内嵌请求图片最多 1 MiB，整次请求合计最多 8 MiB、32 张图片。DSH 复用附件服务，按 2048 × 2048 总像素目标等比例缩放并压缩请求版本，保留原始附件；压缩仍超限时提示缩小图片，历史图片总量超限时通过原生记录流程释放较早图片后重试。限制按压缩后的原始字节计算，平台同时保留足够的 data URL 长度容纳 base64 膨胀。HTTPS 图片 URL 计入数量限制，内容由供应商解析，不把 URL 长度视作远程图片大小。这些限制属于平台聊天传输约束，不代替供应商自身的媒体限制。

未开放的模型可以先保存不完整的资料。正式开放对话前校验上下文、最大输出以及渠道、价格等接入条件。桌面目录缓存最多 30 秒；保存参数后可在桌面端刷新模型目录，运行时按当前配置校验请求。

模型资料、模型与渠道关联以及价格沿用 New API 的管理和同步机制。相同模型可被多个渠道复用，删除渠道只移除其关联，不要求为新渠道重复创建模型。网关模型的价格只在 New API 中维护，能同步的价格先预览导入，无法获取时由管理员在原生定价分区填写；展示资料和模型能力参数不会生成价格。Actvero 调用原生计费预检查，根据价格表达式、分组倍率、上下文与本次输出限制计算预留，再按确认的 New API 消费日志换算积分；不需要填写固定的单次美元预留。无可靠预留、未知计量和无法匹配的账单不会按免费处理。部署需使用包含 Actvero 预检查扩展的网关，构建与权限说明见 [New API 集成](../integrations/newapi/README.md)。

管理员可直接在渠道中测试上游连接，复用 New API 的模型映射、接口选择和请求适配，不要求先配置模型资料、价格或成员积分。该入口仅供组织管理员诊断；自动健康检查与正式成员调用仍遵循原有计费要求。结果显示模型、接口、耗时及上游返回的 Token 用量，费用标为未计价，并以组织内的诊断事件记录，不混入成员消费统计。测试可能消耗供应商账户用量，成功不会自动开放成员访问。

数据看板使用 New API 原生的模型调用分析、分流和用户统计组件，直接读取其用量与性能数据。共享网关按当前组织的私有调用身份、模型和分组限定查询，不能通过用户名或用户 ID 查询其他组织。用户统计中的身份代表组织网关服务账户；成员积分、额度和逐人成本继续在 Actvero 对应管理页面查看。管理员诊断记录不充当已计价消费。

下文介绍未配置 New API 网关时的直接管理模式。

## 操作

添加模型支持从公共库创建和手动创建。公共库提供 models.dev 的模型资料，可按名称、模型 ID、开发方或供应商搜索筛选，查看参数后带入编辑表单。预填展示名称、技术名称、开发方、已知的上下文与输出限制、能力声明和图标；未知参数保留未知，所有参数均可修改。参考报价作为资料保存，不自动设置成员预算价格或采购价格，也不会创建渠道映射。公共库暂不可用或没有匹配结果时，仍可手动创建。

手动创建直接填写模型名称、技术名称和模型类型。两种方式均可在没有渠道时点击“创建模型”，保存为未开放的模型；渠道和上游模型 ID 在“渠道与路由”中另行关联。渠道管理中的创建入口仍可预填所选来源，作为可选快捷方式。

“保存草稿”不会开放新模型。“保存并启用”会校验当前用途的参数、来源状态、成员预算价格与组织积分换算，并一起启用模型、当前用途及选中的固定来源。自动调度仍需明确选择参与调用的来源。停用或归档的渠道需要在渠道管理中恢复，启用模型不会改变渠道的全局状态。

启用前检查可跳转到来源、参数、价格和使用范围。默认使用范围为仅管理员；配置有效不等于上游调用已测试成功。不同用途可以有不同参数和计量类型，来源相似不代表能力完全相同。

## 参数与价格

公开资料匹配同时核对供应商和模型 ID，仅补全空白参数，不覆盖手工填写的值，也不自动导入价格。没有精确匹配或资料暂不可用时，可手动填写或打开完整公开资料选择器核对；缓存资料会明确标注。

成员预算价格用于计算成员调用扣减的积分，渠道采购价格用于统计各来源的上游成本，两者分别维护。价格页直接显示积分换算结果。未配置采购价格表示成本未知，不能解释为免费；确实免费的单价应显式填写 0。参考报价需要核对适用条件后再导入。

技术标识与显示名称分开；修改技术标识可能影响客户端请求。平台可用的目录字段以实际 OpenAPI 与返回值为准。

## 生命周期

归档模型会关闭正式调用；恢复后需明确重新开启。保存的绑定、价格和操作资料不因归档自动抹除。并发配置冲突应读取最新版本后处理。
