# 模型管理

模型与渠道独立管理，通过渠道映射关联。模型维护对成员公开的标识、展示资料、参数、价格和使用范围；创建模型无需先配置渠道。

## New API 网关模式

组织配置 New API 网关后，模型入口使用其原版模型管理、供应商管理、资料同步和定价组件，沿用模型名称、名称匹配规则、标签、图标、端点声明与展示策略。新建和编辑使用同一表单；保存模型资料不要求已有渠道，也不会创建渠道或自动配置价格。

模型列表同时列出已保存的资料和渠道中尚未补充资料的模型，主要显示成员开放范围、接入检查、生效定价和可用渠道数。广场展示、渠道与分组、标签和同步策略可从列设置中查看；资料匹配规则只维护元数据，成员访问针对具体模型配置。名称匹配只影响资料归属，价格按具体模型配置。定价编辑保留原版计费表达式、分档、输入输出与缓存价格、货币和费用预览；未设置价格仍显示未设置，显式保存的 0 才表示免费。

“同步资料”先加载公共资料预览，可搜索本站模型或上游模型列表，逐项选择新增模型与覆盖字段，确认后再应用。同步保留来源和记录版本校验；不自动修改渠道、分组访问权限或价格。“同步价格”单独预览并选择来源，价格写入保留版本校验。供应商支持资料维护、关联模型查询、归属分配、合并和删除前的影响预览。

模型资料、定价、渠道与分组、访问管理位于同一个模型窗口，各分区分别保存。点击列表中的模型名称打开窗口，再选择“访问管理”标签；列表不再放置独立的访问管理按钮。点击价格可打开定价分区。切换标签保留未保存的访问设置，关闭时提示放弃修改；访问保存中不能关闭窗口。

“访问管理”维护 Actvero 成员授权，独立于 New API 的广场展示策略。界面只配置开放开关和使用范围（仅管理员、全体成员或指定成员），不再选择客户端用途或手动填写模型参数。未开放设置可以在渠道、价格或参数尚未完善时保存。正式开放前自动校验调用连接、启用渠道、价格、美元积分换算和必要参数；正常时显示就绪状态，缺项时显示原因和相关入口，保存时再次校验。检查不调用供应商或启动额度时钟。已开放模型的渠道后续异常时，保留授权设置并单独标注接入问题。实际登录、访问密钥和请求额度仍在正式调用时校验，配置就绪不保证真实连通性。组织管理员权限与 CSRF 在服务端校验，New API 管理令牌不进入浏览器。云 GPU 部署不包含在此入口。

“访问管理”中的对话参数自动识别并以只读摘要展示：根据当前调用分组的启用渠道及模型映射，查询随版本维护的 pi-ai 能力参考和 DSH DeepSeek 能力资料。参考资料只提供上下文、输出与推理档位，不代替供应商模型列表，也不导入参考价格。已有向量等用途及其专用参数保持原值，编辑访问设置不会重设为对话用途。桌面端从授权目录读取参数，用户可以选择支持的推理档位和本次输出上限。最大输出能力与默认输出量分别提供，默认输出最多 8192 Token。

火山 Agent Plan 的标准接入模板优先使用经核对的供应商能力资料，覆盖当前公开文本模型的上下文、输出及已确认的图片输入和推理档位；摘要显示资料来源与核对日期。仅确认供应商默认思考方式的模型保留默认选项，不猜测可调档位。始终思考的模型不提供关闭选项，正式调用也拒绝过期的关闭设置。该资料只适用于完整匹配的火山模板，不按模型名称将其套用于其他供应商或自定义地址。改变渠道映射后，后台检查、桌面目录和调用准入使用同一套当前资料重新解析。

New API 调用别名中的内部英文空格原样保留，检查、访问设置与桌面目录使用同一名称，不自动改名。网关调用标识最长 128 字符，需以英文字母或数字开头，不含首尾空格、逗号或控制字符；直接管理模式的技术名称沿用不含空格的规则。不支持的名称明确提示格式问题，不持续显示加载中。接入检查直接显示未关联渠道、缺少能力资料或未配置价格等原因。展示资料缺失不等于运行参数缺失，保存展示资料不会自动开放成员访问。

自动摘要同时显示当前通道的输入、输出类型，默认输出与推理档位，以及工具调用、流式输出、结构化输出的声明。补充功能声明读取锁定 LiteLLM 包内的离线模型资料，不在请求时下载能力表或导入其价格。没有明确证据或候选记录不一致时显示未识别，不把所有对话模型都视为支持工具或结构化输出；各来源共有的上下文和推理参数仍可识别。已维护的图片输入声明通过同一授权目录传给 DSH，文本模型不额外声明图片能力。当前平台对话通道只接入文本和图片输入、文本输出，不因供应商原生支持而宣告音频、视频或原生 PDF 可用。

图片对话通过目录中的 `image_input` 提供传输限制：单张内嵌请求图片最多 1 MiB，整次请求合计最多 8 MiB、32 张图片。DSH 复用附件服务，按 2048 × 2048 总像素目标等比例缩放并压缩请求版本，保留原始附件；压缩仍超限时提示缩小图片，历史图片总量超限时通过原生记录流程释放较早图片后重试。限制按压缩后的原始字节计算，平台同时保留足够的 data URL 长度容纳 base64 膨胀。HTTPS 图片 URL 计入数量限制，内容由供应商解析，不把 URL 长度视作远程图片大小。这些限制属于平台聊天传输约束，不代替供应商自身的媒体限制。

同名模型背后有多个不兼容的上游时，自动识别会提示冲突，需要核对映射或使用不同模型名称。尚无可靠能力资料时显示未识别，补齐对应能力资料前不能开放，不猜测上下文或推理档位。后台每次目录读取和调用准入都会按当前映射重新解析能力；桌面目录缓存最多 30 秒，过期档位在服务端校验。调整模型映射后请重新选择或刷新桌面模型。

网关模型的价格只在 New API 中维护。Actvero 调用原生计费预检查，根据价格表达式、分组倍率、上下文与本次输出限制计算预留，再按确认的 New API 消费日志换算积分；不需要填写固定的单次美元预留。无可靠预留、未知计量和无法匹配的账单不会按免费处理。部署需使用包含 Actvero 预检查扩展的网关，构建与权限说明见 [New API 集成](../integrations/newapi/README.md)。

## 操作

添加模型支持从公共库创建和手动创建。公共库提供 models.dev 的模型资料，可按名称、模型 ID、开发方或供应商搜索筛选，查看参数后带入编辑表单。预填展示名称、技术名称、开发方、已知的上下文与输出限制、能力声明和图标；未知参数保留未知，所有参数均可修改。参考报价作为资料保存，不自动设置成员预算价格或采购价格，也不会创建渠道映射。公共库暂不可用或没有匹配结果时，仍可手动创建。

手动创建直接填写模型名称、技术名称和模型类型。两种方式均可在没有渠道时点击“创建模型”，保存为未开放的模型；渠道和上游模型 ID 在“渠道与路由”中另行关联。渠道管理中的创建入口仍可预填所选来源，作为可选快捷方式。

“保存草稿”不会开放新模型。“保存并启用”会校验当前用途的参数、来源状态、成员预算价格与组织积分换算，并一起启用模型、当前用途及选中的固定来源。自动调度仍需明确选择参与调用的来源。停用或归档的渠道需要在渠道管理中恢复，启用模型不会改变渠道的全局状态。

启用前检查可跳转到来源、参数、价格和使用范围。默认使用范围为仅管理员；配置有效不等于上游调用已测试成功。不同用途可以有不同参数和计量类型，来源相似不代表能力完全相同。

## 参数与价格

公开资料匹配同时核对供应商和模型 ID，仅补全空白参数，不覆盖手工填写的值，也不自动导入价格。没有精确匹配或资料暂不可用时，可手动填写或打开完整公开资料选择器核对；缓存资料会明确标注。

成员预算价格用于计算成员调用扣减的积分，渠道采购价格用于统计各来源的上游成本，两者分别维护。价格页直接显示积分换算结果。未配置采购价格表示成本未知，不能解释为免费；确实免费的单价应显式填写 0。参考报价需要核对适用条件后再导入。

技术标识与显示名称分开；修改技术标识可能影响客户端请求。平台可用的目录字段以实际 OpenAPI 与返回值为准。

## 生命周期

归档模型会关闭正式调用；恢复后需明确重新开启。保存的绑定、价格和操作资料不因归档自动抹除。并发配置冲突应读取最新版本后处理。
