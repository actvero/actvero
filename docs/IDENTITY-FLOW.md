# 身份与授权

Web 使用 OIDC 授权码流程与服务端会话。外部身份按 issuer + subject 唯一关联，不通过邮箱自动接管已有账号。浏览器写请求同时检查会话、组织资格和 CSRF。

## 成员与角色

组织成员包含管理员和普通成员。成员的暂停、移除及资源撤权影响后续受控访问；恢复成员资格不会自动复活已撤销会话。最后一名有效管理员受到事务与并发保护。

## Web 与设备会话

Web、桌面和管理 CLI 使用独立凭据及策略。持久登录需显式配置，不能用调整策略延长旧会话原本的期限。设置页可查看和撤销本人设备。

桌面强制切换账号时显示可填写新账号的登录表单；普通 Web 重新认证沿用其认证上下文。站内返回地址在客户端与服务端都需要校验。

## 配置

应用 URL、OIDC issuer、浏览器回调和 Keycloak 客户端必须一致。反向代理部署见 [同源身份入口](SAME-ORIGIN-IDENTITY.md)。
