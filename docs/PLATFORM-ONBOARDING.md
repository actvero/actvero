# 初始化与组织开通

新实例根据 `ACTVERO_PLATFORM_EDITION` 采用社区或 SaaS 初始化流程。社区模式创建一个组织及首位管理员；SaaS 模式先建立平台运营入口，再管理组织开通。

## 操作流程

访问 `/console`，按页面完成初始化并跳转身份服务登录。初始化完成后不会因重启或清除浏览器状态再次开放。Keycloak bootstrap 管理员不是业务管理员。

SaaS 组织开通支持后台配置的注册、邀请与审核方式。平台运营人员维护开通策略、申请和邀请；组织管理员维护自己的成员和资源。

## 身份与邀请

邀请只用于指定流程与目标身份，按有效期和状态校验；登录成功并不自动意味着邀请已接受。已有账号应通过本人真实登录确认，不能用邮箱覆盖原密码或接管身份。

公开首页开关与组织开通策略独立，关闭门户不会自动关闭登录、下载或组织开通。
