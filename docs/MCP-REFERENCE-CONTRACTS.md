# MCP 引用契约

专家发布中的 MCP 引用包含客户端需要核验的能力与修订信息。资料、执行定义和连接状态按不同维度表达，不能用一个“版本已更新”涵盖全部变化。

## 核验

按实际引用类型核验工具定义、所需配置和平台可披露的修订。服务名称与说明不是能力证明；服务端在执行时仍重新检查当前权限。

## 客户端消费

引用用于限制专家上下文中的工具集合；不可用依赖应显示原因并按用户选择更新。规范字段见 [专家格式契约](contracts/expert-manifest-v1.schema.json) 与 [OpenAPI](api/openapi.json)。
