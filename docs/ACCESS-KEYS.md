# 个人访问密钥

成员在个人设置的访问密钥入口创建和撤销密钥。秘密只在创建时展示，服务端保存校验所需摘要；不能从历史列表重新读取原文。

## 权限

密钥的使用权受当前成员资格、密钥范围、资源开关与实时授权共同约束。管理员密钥没有绕过普通模型或工具调用权限的特权。

## 使用

对已支持的资源接口使用 Bearer 凭据。模型请求同时受成员额度约束；桌面登录与管理 CLI 使用独立会话，不能用个人密钥替代这些登录协议。

到期、撤销或成员失效后，后续访问应被拒绝。将密钥保存在调用方的秘密管理机制中，不写入源码或公共示例。
