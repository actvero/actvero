# 平台运营

平台运营提供组织、申请、邀请、站点品牌、邮件模板和客户端下载设置。组织管理员管理本组织资源，两类资格分别检查。

## 入口与权限

SaaS 模式使用 `/platform`。平台运营身份不会自动成为所有组织成员，也不会绕过组织资源、模型调用或个人连接的权限校验。

## 维护

先配置可信应用地址、身份入口和正式 SMTP，再使用邀请与身份邮件。品牌素材与站点设置由平台统一维护；组织名称和成员个人头像属于各自业务对象。

各类资源的启停、授权和版本发布保持独立，不把保存设置视为已验证外部服务连通。
