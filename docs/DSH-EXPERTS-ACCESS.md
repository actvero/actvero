# 桌面专家接入

桌面以当前成员身份读取专家分类、目录和可用发布版本。类别来自平台字典，不应硬编码组织私有分类。

## 版本与依赖

按发布摘要获取不可变内容，再解析所需 Skill 和 MCP 引用。解析状态可能表示缺少授权、依赖不可用或需要更新，不能一律解释为下载失败。

## 工具范围

专家上下文只能使用发布配置允许的工具集合。服务整体开放并不代表当前专家允许全部工具。格式见 [manifest schema](contracts/expert-manifest-v1.schema.json) 与 `contracts/` 中的发布示例。
