# 桌面 MCP 接入

桌面首先完成平台登录与组织选择，再取得适用资源令牌和成员可见目录。桌面调用始终按真实成员权限执行，不继承管理员后台测试旁路。

## 连接流程

读取服务目录与个人连接状态。服务需要用户凭据或 OAuth 时，通过对应连接流程完成；浏览器授权结果还需绑定原设备与请求状态确认。

## 请求与恢复

使用平台提供的单服务 MCP 入口，按协商的协议交换消息。资源目录、凭据和 OAuth 状态不能混入日志。遇到撤权应清除相关缓存并停止调用；暂时失败与需要重新授权分别处理。
