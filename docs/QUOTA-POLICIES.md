# 额度策略

组织管理员维护额度策略并分配到成员。个人访问密钥和桌面模型调用共同受该成员当前额度约束。

## 配置与分配

策略是可复用的额度模板。周期限额可以同时设置多个固定时长窗口，例如 5 小时和 168 小时；每个窗口都必须满足。不限额度使用独立模式，不配置周期上限；0 积分仍表示零额度。

每名成员可以指定一套策略，未指定时继承组织默认策略，之后加入的成员同样继承默认。管理员身份不自动获得不限额度。策略分配不会授予模型访问权限；上游余额、服务限流和成员资格继续独立校验。

管理员在“策略”中维护模板，在“成员分配”中选择继承默认或指定策略。分配使用版本校验，遇到并发修改需刷新后重试。仍有成员使用的策略必须先重新分配才能归档，组织默认策略不能归档。暂停成员仍显示已配置策略并允许解除指定，但不能新增分配或调用模型。

升级会将每名成员原先最高优先级的生效策略转换为显式分配；原本使用默认策略的成员继续继承。已有时间窗口、预留、消费记录与历史积分换算保持不变。

## 受理与结算

受理请求时按策略检查并预占，终态根据有效计量与历史价格结算。未知结果可能需要保留预占和后续核对，不能因客户端取消就假定没有费用。

不限额度只取消成员积分上限校验，仍记录计费预估、实际用量、成本和结算状态。缺失计量继续待核对，不能当作免费调用。切回周期限额时，当前时间窗口内的已有消费和未结算预留继续计入额度。

预占、待核对与已结算记录都按受理时间归属各自的半开时间窗口，结束时刻不计入原窗口。旧记录不会继续占用已经重置的新周期；仍未结束的其他窗口继续计算该记录。迟到结算或人工更正保留原受理时间和历史换算比例，不删除历史账务。

固定时长窗口从首笔成功准入起算，到期后只查看余额不会启动新窗口。切换策略时长再切回，仍需计算上一个窗口结束后、当前时长范围内的已有消费与预占。7 天额度使用相同规则，时长固定为 168 小时，不按周一或本地日历重置。升级前已有消费的自然周保留当前结束时间；之后按 168 小时起算。若旧策略同时含自然周与 168 小时，迁移采用较小上限，首个过渡周期覆盖两个活动窗口，保留两者已用与预留；结束后恢复普通 168 小时周期。

## 统计

多个时间窗口分别判定。历史统计使用明确时区、时间范围和计量单位；不同单位不可直接相加，缺失数据不可补零。

看板中的“未结算预估积分”包含进行中和待核对的历史记录，不等同于当前周期的额度占用。当前余额以各周期内的已用积分和预留积分计算。
