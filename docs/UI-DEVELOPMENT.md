# 界面开发规范

界面优先复用 `frontend/src/components/ui/` 的共享控件、布局和表格组件。业务表单沿用 React Hook Form 与 Zod，路由与整页业务实现分离。

## 主题与交互

颜色、间距和状态通过统一语义主题表达。新增流程覆盖加载、空、失败、无权限、提交中和窄屏状态；图标按钮提供可访问名称，确认操作使用现有弹窗。

字段错误关联具体输入。用户文案说明可采取的动作，不把缓存、数据库或实现内部机制作为普通表单步骤。

## 身份页面

身份服务读取共享控件样式与编译 CSS。修改主题后同时构建 Web 与身份主题，并检查浅深色和窄屏，不能只验证其中一个入口。
